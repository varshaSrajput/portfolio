# Varsha Rajput Portfolio

A simple, responsive, editable HTML/CSS portfolio built with Bootstrap 5.

## Files
- `index.html` — home page and skill overview
- `projects.html` — projects and live demo links
- `about.html` — profile, skills, experience, education, publication, and activities

## Run locally
Open `index.html` in a browser. An internet connection is needed to load Bootstrap from its CDN.

## Edit your details
Open the HTML files in VS Code or any text editor. Search for the text you want to update and save the file.

## Deploy with Netlify
1. Extract this ZIP.
2. Open Netlify and choose **Add new site** / manual deploy (or connect a GitHub repository).
3. Upload the extracted folder or deploy the repository.
4. Ensure `index.html`, `projects.html`, and `about.html` are in the published root folder.

## Notes
- The portfolio uses a initials avatar instead of a profile photo because no photo asset was included in the uploaded ZIP.
